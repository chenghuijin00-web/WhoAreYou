# 首次加载优化（2026-11-11）

## 范围

保留角色、透明背景、眼眶相对坐标、900ms吐舌、待机动画、题库和计分；不修改数据库、服务器根入口或Nginx配置。不新增应用依赖，压缩使用本机已有Sharp，构建不依赖Sharp。

## 素材与缓存

原PNG不删除，供回退及旧客户端使用。当前页面改用 `src/assets/optimized/` 中的WebP，Vite生成内容指纹地址，复用线上 `/PMD/assets/` 的7天缓存；HTML继续校验更新，素材变化自动产生新地址，不用随机参数强刷缓存。

## 加载行为

- HTML优先预加载背景图，组件共用同一地址，避免等JS执行后才发现背景。
- Test、Result改为异步路由，首页不请求结果图表库；保留结果页现有逻辑。
- `ProgressiveImage.vue` 保留原尺寸占位，图片成功加载后再显示；失败不暴露破图图标。
- 非首屏图片距离视口120px时请求；网络失败间隔400ms、1200ms最多重试两次，永久失败保留占位。旧节点事件不得覆盖新图片状态，卸载清理重试和观察器。
- 背景加载失败仍可通过原备用按钮开始答题，不必等待图片。

## 验证

`npm.cmd run typecheck`、`npm.cmd run test:personality`、`npm.cmd run test:hero`、`npm.cmd run build`、`npm.cmd run test:loading`、`git diff --check`。

浏览器验证：首页请求不含Test/Result/ECharts、不再请求原始大PNG；远处图片延后；临时失败恢复、永久失败停止重试；多尺寸布局与900ms动画；团队页跳转；两轮完整答题与分享；自动跳转改选。

200KB/s、150ms延迟、禁用缓存的本地模拟中，背景约1.1秒就绪。它不是公网或真机耗时承诺，实际仍受带宽、延迟、设备与缓存影响。结果页图表包仍有大包警告，但不进入首页请求链。
