# 奶蛙使用统计

仅 Cloudflare 根路径构建启用。管理员页面是 `/admin/usage`，页面不对外提供导航；数据接口还必须验证管理员令牌，并禁止缓存，知道地址不能查看数据。令牌每次查询后清空，不放在链接或浏览器存储。

| 指标 | 何时计一次 |
| --- | --- |
| 访问 | 一次应用打开中第一次进入正常页面；站内切页不重复，浏览器刷新可另计 |
| 开始答题 | 新一轮答题成功初始化 |
| 完成答题 | 最后一题已提交，无需打开结果页 |
| 生成海报 | 原图生成并成功交付预览，不等于保存到相册 |
| 复制分享 | 自动复制成功，手动选中文本复制不能可靠监测 |

按北京时间保留每日汇总，展示累计与最近 30 天。完成率是同期完成次数除以开始次数，不追踪个人答题流程；跨日提交或漏报时单日比值可能超过 100%。统计不回填、不代表独立访客，不保存答案、结果、身份、IP 或设备标识，尊重 GPC 和 Do Not Track。

## 首次启用（需要 Cloudflare 项目管理员）

1. 创建专用 D1，例如 `whoareyou-usage`。把实际数据库 ID 写入 `wrangler.jsonc` 的 `env.production.d1_databases`，绑定名称为 `USAGE_DB`，`database_name` 用实际名称，`migrations_dir` 为 `migrations`。只绑定生产环境；预览如需统计，使用独立数据库。
2. 核对账号和目标数据库后，由管理员在 Cloudflare D1 控制台对该专用数据库执行一次 `migrations/0001_usage_daily.sql`，不要在其他项目的数据库上运行。
3. 在 Pages 项目的生产环境新增加密变量 `USAGE_ADMIN_TOKEN`。使用密码管理器或者本地加密随机工具生成 32 字节随机值、以 64 个小写十六进制字符表示。不要发到聊天、保存在命令历史或提交到仓库。
4. 部署后走一次完整答题，确认未授权请求看不到统计，再输入令牌检查五项计数。未配置数据库或令牌时统计接口会返回不可用，主页及答题不受影响。

接口是公开站点的匿名计数入口，来源校验用于防止普通跨站网页直接写入，不等同于机器人防护。数据用于观察趋势，不用于计费；如出现恶意刷量，按站点实际流量为 `POST /api/usage` 配置边缘限流。若要暂停统计，可撤下生产的 `USAGE_DB` 绑定并重新部署，不需要删除数据。
