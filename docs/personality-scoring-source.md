# 公开计分方案选择与适配

> 当前本地版本 v7：奶蛙启用娱乐类型分配，不再显示 X。原始计分不变；有分差按高分侧，平分按固定题号首个非中立答案决胜；该组全中立时使用 INFP 对应字母作为默认赠送，并披露无倾向证据。下文 v3～v6 记录为历史背景，旧配置默认仍兼容保守模式。

## 选择

2026-11-10 选择独立实现 IPIP 官方公开的五级正反向求和规则。不是复制某个 GitHub 仓库，没有引入第三方运行时依赖。

- 规则原文：https://ipip.ori.org/newScoringInstructions.htm
- 材料使用说明：https://ipip.ori.org/newPermission.htm
- IPIP 说明其材料处于 public domain，可用于商业或非商业目的。
- OEJTS 原站开发页 https://openpsychometrics.org/tests/OJTS/development/ 在 Appendix B 标明 CC BY-NC-SA 4.0；因本项目可能商业化，没有复制它的题目、实现、参数或说明文本。

## 采用和未采用的部分

采用：按题目方向对响应正向或反向计分，再逐量表求和。最初五档采用1至5分和6减响应值；当前三档原创适配采用1至3分和4减响应值。

未采用：IPIP 任何具体标准量表题库、人口常模、验证数据；未声称本题库是 IPIP 量表。IPIP 中的大五量表不能无条件等同于 MBTI，本轮没有这样映射。也没有宣称实现了官方 MBTI、16Personalities 或 IRT。

当前 v6 是28道原创四维生活情境题，每题固定3个短选项。本轮对公开正反向计分思路作独立工程实现与三档响应适配，不是原版五档 IPIP 问卷；不能把计分思路的来源当成对本站题目效度的背书。

## 数据与计算

- `Question.scoringKey`：所属scale和direction，正反向取1或-1。
- `TestConfig.responseLevels`：v6 明确为3；旧配置未指定仍默认5。
- `Option.responseValue`：固定顺序为行为一1、中间2、行为二3，页面不展示字母。
- 正向处理响应 = responseValue；反向 = 4-responseValue。
- 每轴7题，rawTotal范围7至21，中点14；归一化 = (rawTotal-7)/14。
- 所有缺答、越界或非整数响应、未知题、重复键、损坏计分方向拒绝计算。不能把缺答或没有经历当中间选项。
- 保留旧 `scores` 兼容字段，并检查其必须与新计分键等价；若两套配置方向不一致，明确报错。
- 结果附原始总分、范围、题数。百分比仅是可达分数范围内的位置，不是常模百分位、准确率或人格概率。
- 0.35至0.65的X展示规则和16种皮肤映射仍是本站产品规则，不来自IPIP。

新旧归一化在数学上等价，本轮不以改变用户结果冒充测量提升。改进是模块可复用、规则可追溯、原始分可核验、坏配置及缺答显式拒绝。题目质量和中文表达验证仍待后续试测。

v6 不是把五档答案直接迁移为三档：移除两个弱偏向选项，缩短全部题干和两侧描述。端点和中点归一化保持一致，但表达和响应粒度改变会影响实际作答；旧结果不可作为同一版问卷纵向比较。16种娱乐皮肤保留；偏好不明确的维度继续显示 X。新增每轴两侧与中间选择次数，不将中间选择伪装成某一侧的明确证据。

## 本轮审查结果

### v4 展示调整（2026-11-10，已部署后被 v5 取代）

- 选项不再显示字母标签，弱偏向选项直接引用具体行为，不依赖 A/B 标识。
- `questionPresentation.ts` 使用 Fisher–Yates 洗牌；每轮开始为每题独立生成顺序，返回改答不重排，重置清空展示题库。
- 不修改原始题库、选项 ID、响应值或分值，计分继续按选项 ID 进行；问卷版本为 `naifrog-16-v4-shuffled`。
- 来源声明按 `scaleScoring` 判断，不依赖版本名称，避免更新版本时意外隐藏计分来源。
- 新增洗牌无丢失/重复、题库不变、五级选项结果等价测试；浏览器回归按内容选择答案，不再依赖位置。
- 本调整不代表测量准确率提升。曾部署至 `naifrog-shuffled-20261110-v10`。
