# 首页大脸交互背景

本地预览：`npm.cmd run dev -- --host 127.0.0.1 --port 5179 --strictPort`，打开 `http://127.0.0.1:5179/PMD/`。本轮不部署服务器。

## 素材

- `public/images/hero-face-base.png` 为内置 imagegen 按用户提供的正面黄色角色参考生成的高清透明底图，不替换旧素材。
- 提示词要点：保留正面黄色圆头、微笑和绿色眼眶，去棕色背景、去两个黑色瞳孔，高清透明底，作为可独立叠加瞳孔的首页背景层。
- 实际眼眶位置按生成素材校准为画布宽度22.7%与75.8%，高度45%。修改图片时须重新校准，不能沿用不同素材的坐标。
- 原PNG约1.7MB保留用于回退；当前页面使用等比缩放的透明WebP约63KB，地址由Vite生成内容指纹并在HTML优先预加载。素材加载失败重试最多两次，再隐藏整张脸及瞳孔；标题和测试入口仍可使用。详见 `performance.md`。

## 交互与布局

- `HeroMascot.vue` 的底图和眼睛为 `aria-hidden` 装饰层；嘴巴、舌头和按钮为独立前景层，不受背景渐隐遮盖。背景不参与命中，仅舌头按钮接收点击，支持鼠标、触摸和键盘。
- `heroGaze.ts` 以各自眼睛中心和视口坐标计算注视向量，限制在椭圆范围内；头部最大偏移3/2px、倾斜0.8度。
- 点击注视保持1.1秒，随后平滑回中。待机每2.2～4秒小幅侧看一次，停留1.4秒再回中；待机视线过渡0.8秒，点击响应仍为0.2秒。没有持续运行的JS逐帧动画循环。
- 已移除旧测试卡片及“今天想测点什么”，嘴巴原位打开后伸出粉色圆润舌头，舌头上显示“点击答题”。桌面端偏右、手机端居中；320/390/768/1024/1366宽度入口完整可见。
- 嘴巴打开、吐舌、文字显现均使用900ms、无延时的动画时间轴，全部在1秒以内完成，不是三个串行动画。舌根固定、伸长时收窄、回缩时稍变宽，随后轻微回弹收敛；文字在后段出现。悬停不改变舌头颜色、亮度和阴影。动画从底图加载完成、元素可见时启动；不把网络等待冒充动画时长。
- 系统选择减少动态时直接展示最终状态。素材尚未加载或失败时提供普通答题按钮，不阻塞进入测试。
- 舌头文字缩小为桌面16～22px、手机16～20px，降低字重；舌尖左右略不对称，增加细腻高光和较浅中缝。
- 舌头表面与嘴沿共享4.8秒的轻微待机节奏，开场900ms结束后启动；表面轻伸缩、摆动，嘴沿同步微收放。开场嘴巴也随吐舌伸长与回弹调整开合。
- 待机动画只改变按钮内部的舌头表面，不持续移动点击区域；前景与底图仍沿用同一头部偏移。离屏和后台暂停CSS待机，减少动态时完全禁用。
- 当前实现恢复为服务器v27：点击先拉长再回弹（620ms），四向拖动松手后回弹（520ms）；下拉伸长、上拉收拢，左右剪切。普通模式回弹后进入答题，纯享模式只回弹。嘴沿与视线联动，不触发全身果冻。
- 回弹期间防重复提交；取消指针、失焦、切换模式、离屏或卸载会取消交互且不跳转。键盘支持同样的回弹入口；系统“减少动态”时跳过动画直接答题。
- 拉动舌头及回弹时，双眼按各自眼眶坐标注视实际舌尖，采用更大的18%限幅和70ms平滑跟随；上拉、下拉都能改变注视位置。此时暂停随机视线，取消后恢复待机。逐帧追踪只在交互期间启用，离屏、减少动态、切换模式及卸载时停止。
- 按住可反复换方向，不设自动跳转倒计时；强拉时舌尖轻颤、眼睛注视更明显。渐进阻力及屏幕限位限制极端形变，减少动态时跳过交互动画。
- 后续曲面、正反面与Blender实验未保留在当前页面。实验源码、模型和素材备份于 `D:/PMD-art-tools/experiments/tongue-post-v27/`，服务器未改动。
- `node --experimental-strip-types scripts/test-tongue-elastic.mjs`：舌根锚定、二维回弹、反向过冲、衰减归零与轻点限幅。
- 后台、离屏、减少动态效果和卸载时统一取消定时器/动画帧；卸载移除监听器和观察器；改变窗口尺寸重新计算。
- 不读取摄像头、陀螺仪，不上传点击坐标；不改答题、计分、题库、结果和服务器配置。

## 验证

首页右上角“纯享模式”隐藏可见文字，保留无文字关闭按钮（也可按 Esc）。纯享下点击或四向拉动舌头可反复回弹玩耍，双眼追踪舌尖、嘴角联动、强拉轻颤，但绝不进入答题。舌头命中层高于角色拖拽层，其余部位仍能轻点压缩回弹、拖动倾斜或拉伸，脸图、眼睛、嘴巴共享底边锚点。开始玩舌头时停止正在进行的全身回弹，避免两套形变叠加。取消、失焦和切换模式均释放交互状态；开启系统“减少动态”时纯享保持静态，普通模式仍可直接答题。

- `npm.cmd run test:hero`：独立双眼坐标、方向、椭圆限位、无效输入与滚动坐标一致性。
- `npm.cmd run test:personality`、`npm.cmd run typecheck`、`npm.cmd run build`。
- 浏览器覆盖320/390/768/1024/1366宽度、三段动画各900ms、文字完全出现、按钮不被首屏裁切、触屏尺寸布局、键盘进入、减少动态、图片失败仍能答题；答题自动跳转和改选有独立回归。
- 真机、弱网和操作系统原生分享仍需后续实测；保留项目既有的大包警告。
